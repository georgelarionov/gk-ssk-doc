# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Что это

Статичный сайт-сборник отчётов «ГК ССК × ИИ-ХАБ». Без фреймворков и сборки — чистые HTML/CSS, страницы правятся напрямую и открываются как есть. Контент и UI — на русском, бренд ГК «ССК» (акцент `--red:#ce1f2d`, шрифты Manrope + JetBrains Mono с Google Fonts).

## Команды

```bash
npm install      # один раз; ставит live-server (единственная зависимость)
npm run dev      # live-server на http://localhost:3000 + автооткрытие браузера
npm start        # то же, но без открытия браузера (--no-browser)
```

Тестов, линтера и шага сборки нет. `live-server` нужен только для авто-перезагрузки при правках; в сами страницы он не входит.

## Архитектура

Две роли файлов, и их **нельзя путать**:

- **`index.html`** — хаб. Шапка + grid карточек отчётов (`.report-grid`, `repeat(auto-fill,minmax(280px,1fr))`). Подключает `styles/main.css`. Каждая карточка-ссылка ведёт на файл в `reports/`.
- **`reports/<slug>.html`** — отдельный отчёт, **самодостаточный**: весь CSS в инлайн-`<style>`, `styles/main.css` он НЕ использует. Наверху — `.backlink` на `../index.html`.

Дизайн-токены (`:root` с `--red`, `--surface`, `--mono` и т.д.) **продублированы** в `styles/main.css` и в каждом отчёте — это осознанно, чтобы отчёт оставался переносимым одним файлом. При смене палитры правь оба места.

## Источник отчётов: handoff-бандлы

Отчёты приходят как «handoff bundle» из Claude Design (claude.ai/design) — папка `claude-handoff/` (в `.gitignore`, не часть сайта). Внутри лежит HTML/CSS/JS-прототип. Процесс реализации нового отчёта:

1. Прочитать прототип целиком (его путь указан в `claude-handoff/README.md`).
2. Перенести в `reports/<slug>.html`, **вычистив артефакты дизайн-тула**: пустые `style=""`, `data-comment-anchor`, теги `<font>`, лишние `<br>`, склейки слов без пробела.
3. Добавить карточку в `index.html` у маркера `<!-- Добавляй новые отчёты сюда -->` и обновить счётчик `.count`.

## Gantt-таймлайн в отчётах

В отчётах часто правят таймлайн — его геометрия неинтуитивна:

- Шкала `.scale` отображает диапазон дат, где `left:0%` = начало, `left:100%` = конец (в `ii-hab.html`: 25 мая → 22 июня, 28 дней). Линия `.today` стоит на проценте текущей даты.
- `.gbar` позиционируется `left`/`width` в **процентах от всего диапазона**. Перевод даты в %: `(дней_от_начала / всего_дней) * 100`.
- Полоса `.prog` (в работе) содержит вложенный `<i>`, чья `width` — это **процент заливки от самой полосы**, а не от диапазона. Принятая конвенция: красная заливка доходит ровно до линии «сегодня». Формула: `i.width = (today% − gbar.left) / gbar.width * 100`.
- Классы полос: `.prog` — в работе (красная), `.future` — запланировано (серая), `.tent` — далее (штриховка).
